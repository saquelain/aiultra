# Learnings

## Background (from the first session, on the Mac)

- About 25 AI-narrated "What If" and history videos posted in August 2026 got **0–14 views** each.
- Older Valorant gameplay clips got **400–2,000 views** each. Real, watchable visuals beat narrated slideshows.
- All 34 old videos were set to private on 2026-10-21 so the channel starts fresh. Nothing was deleted.
- New format chosen: code-generated physics simulation ("can the ball escape all the rings?"), with no words and synthesized music, so it works in any language.
